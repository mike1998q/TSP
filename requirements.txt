# NOTE on RTX 5090 (Blackwell, sm_120) + CUDA 13.0:
#   Blackwell GPUs need a PyTorch build compiled for CUDA 13.x. The verified
#   local setup for this project is torch 2.11.0+cu130, installed from the
#   cu130 wheel index:
#     pip install torch==2.11.0 --index-url https://download.pytorch.org/whl/cu130
#   Do NOT install the default PyPI wheels -- they lack sm_120 kernels and
#   fail with "no kernel image is available for execution on the device".
#   See README.md -> "Installation".
#
# torch is left loosely pinned here so this file stays install-safe on
# machines without the Blackwell wheel; install torch via the index-url above.
